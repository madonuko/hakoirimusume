## Quick Reference

| Macro | Description |
|-------|-------------|
| `%define` | Define a local macro |
| `%global` | Define a global macro |
| `%autosetup` | Uncompress and setup sources |
| `%configure` | Run configure script |
| `%make_build` | Build with make |
| `%make_install` | Install with make |
| `%cmake` | Run CMake |
| `%meson` | Run Meson |
| `%find_lang` | Generate language file lists |
| `%bcond_with` | Disable conditional build |
| `%bcond_without` | Enable conditional build |
